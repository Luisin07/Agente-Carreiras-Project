Projeto Agente de Carreira Adaptativa (ACA)
O Agente de Carreira Adaptativa (ACA) é um projeto acadêmico desenvolvido em Python com foco em automação e Inteligência Artificial, que explora como Large Language Models (LLMs) podem apoiar profissionais diante das transformações do mercado de trabalho impulsionadas pela IA.

O agente atua como um assistente inteligente de carreira, capaz de analisar o impacto da automação sobre diferentes profissões e orientar o usuário na tomada de decisões estratégicas por meio de Upskilling (evolução das habilidades atuais) e Reskilling (aquisição de novas competências para transição de carreira).

🎯 Objetivo do Projeto
Demonstrar, de forma prática, como a Inteligência Artificial pode ser utilizada para:

Avaliar o risco de automação de uma profissão.

Identificar habilidades críticas para o futuro do trabalho.

Sugerir caminhos personalizados de upskilling e requalificação.

Simular entrevistas de emprego com base em critérios estruturados.

✨ Funcionalidades
Análise de Perfil e Risco: Estima o impacto da automação nas atividades profissionais e destaca habilidades essenciais.

Plano de Upskilling: Recomenda áreas de aprimoramento alinhadas às demandas tecnológicas atuais.

Caminho de Requalificação: Sugere novas competências para transição de carreira, considerando habilidades transferíveis.

Simulação de Entrevista: O agente assume o papel de recrutador para testar a profundidade técnica do usuário na nova função.

🛠️ Tecnologias Utilizadas
Python 3

Jupyter Notebook (Google Colab)

OpenAI API (GPT-4/GPT-3.5)

Engenharia de Prompt (Criação de personas e encadeamento de lógica)

🚀 Como Executar
Abra o arquivo agente_carreira_aca.ipynb no Google Colab ou Jupyter Lab.

Obtenha sua chave de API da OpenAI em platform.openai.com.

Configure sua chave no notebook conforme o exemplo abaixo:
