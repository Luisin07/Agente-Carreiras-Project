# Projeto Agente de Carreira Adaptativa (ACA)

O **Agente de Carreira Adaptativa (ACA)** é um projeto acadêmico desenvolvido em Python com foco em **automação e Inteligência Artificial**, que explora como **Large Language Models (LLMs)** podem apoiar profissionais diante das transformações do mercado de trabalho impulsionadas pela IA.

O agente atua como um **assistente inteligente de carreira**, capaz de analisar o impacto da automação sobre diferentes profissões e orientar o usuário na tomada de decisões estratégicas por meio de **Upskilling** (evolução das habilidades atuais) e **Reskilling** (aquisição de novas competências para transição de carreira).

## Objetivo do Projeto
Demonstrar, de forma prática, como a Inteligência Artificial pode ser utilizada para:
- Avaliar o **risco de automação** de uma profissão
- Identificar **habilidades críticas** para o futuro do trabalho
- Sugerir caminhos personalizados de **upskilling e reskilling**
- Simular entrevistas de emprego com base em critérios estruturados

## Funcionalidades
- **Análise de Perfil e Risco de Automação:** estima o impacto da automação nas atividades profissionais e destaca habilidades essenciais para o futuro.
- **Plano de Upskilling Personalizado:** recomenda áreas de aprimoramento alinhadas às demandas tecnológicas atuais.
- **Caminho de Reskilling:** sugere novas competências para transição de carreira, considerando habilidades transferíveis.
- **Simulação de Entrevista:** realiza uma entrevista simulada para a nova função, avaliando clareza, relevância e profundidade das respostas.

## Tecnologias Utilizadas
- Python  
- Jupyter Notebook (Google Colab)  
- OpenAI API (LLM)  
- Engenharia de Prompt  

## Contexto Acadêmico
Projeto desenvolvido para a disciplina **Prompt and Artificial Intelligence**, no curso de **Ciência da Computação**, com foco na aplicação prática de IA, automação e lógica de agentes inteligentes.

O ACA reforça a importância da **adaptação profissional contínua** em um cenário cada vez mais automatizado, mostrando como a Inteligência Artificial pode ser uma aliada estratégica no planejamento de carreira.
